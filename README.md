# Ye Teng's portfolio

This repository contains my personal website for DSC 106 Labs 1 and 2. It includes a home page, a responsive project gallery, a grid-based contact form, and a styled semantic HTML resume.

## Preview locally

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.
