# Ye Teng's portfolio

This repository contains my personal website for DSC 106 Labs 1–3. It includes a home page, a responsive project gallery, a grid-based contact form, a styled semantic HTML resume, JavaScript-generated navigation, and a persistent three-state theme switcher.

## Preview locally

Lab 3 requires a local server. Run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.
