# Ye Teng's portfolio

This repository contains my personal website for DSC 106 Labs 1–4. It includes a home page, a responsive data-driven project gallery, a grid-based contact form, a styled semantic HTML resume, JavaScript-generated navigation, a persistent three-state theme switcher, and live GitHub profile statistics.

## Preview locally

Labs 3 and 4 require a local server. Run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.
